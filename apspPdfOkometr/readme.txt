This tool can be used to quickly compare pairs of PDF files in a given directory (compare with your own eyes, that is).

Files in a pair must have the same name with different one-letter prefix, first file gets the prefix "A", second gets "B".
    e.g. `ADocument123.pdf` and `BDocument123.pdf` will be paired.

Choose file in a grid to show it in the viewer.

Press the Enter key to switch between files in a pair.

Ctrl+MouseWheel to zoom.
